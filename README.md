# Sukkur Client Quotation Generator

Build a clear PKR quotation for a school, clinic, shop or institute website in
seconds — with a full price breakdown, copy and WhatsApp share, and saved
quotations.

## What it does

- Quotation form: client / business name, business type (School, Clinic,
  Shop, Institute, Other), website type, number of pages, and extras
  (Mobile responsive, WhatsApp button, Contact form, Google Map, Photo
  gallery, Urdu / English content).
- Live PKR quotation with a full breakdown: base price + extra pages +
  extras = total. No hidden charges.
- Starting prices for Sukkur local work:
  - Landing page from Rs. 8,000 (1 page included)
  - Basic website from Rs. 10,000 (3 pages included)
  - Full responsive website from Rs. 15,000 (5 pages included)
  - Extra pages Rs. 1,500 each
- Quotation summary card: copy as text, or share on WhatsApp (opens
  wa.me with the quotation prefilled — no phone number is hardcoded).
- Save quotations in your browser (localStorage) with date, client name and
  total; load a saved quotation back into the form, or delete it.

## How to use it

1. Open `index.html` in any browser — it works offline, no sign-in needed.
2. Change the client name, business type, website type and pages, and tick
   the extras the client needs.
3. The quotation updates live. Copy it or share it on WhatsApp.
4. Click **Save this quotation** to keep it in the saved list below.

## Demo data

The form is pre-filled with a demo example (a school in Sukkur asking for a
full responsive website). Change it to make a real quotation. Demo prices
only — confirm the final price with the client before starting work, and
never put a password, phone number, CNIC number or bank detail into a
quotation.
